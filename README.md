# نَغَم ستوديو — NAGHAM Studio

**الملف الجاهز:** [`nagham-studio.html`](nagham-studio.html) — ملف واحد مستقل (HTML + CSS + JS) يعمل بفتحه مباشرة في المتصفح، بدون خادم وبدون تثبيت.

هذه نسخة أُعيد بناؤها من الصفر انطلاقًا من واجهة `spotify_studio_2026` القديمة: نفس الفكرة (مشغل موسيقى عربي فاخر)، لكن بهندسة أنظف، بلا Tailwind CDN أو Lucide CDN، وبلا صور base64. الأيقونات كلها SVG مضمّنة، وأغلفة الألبومات تُرسم برمجيًا.

## ما الذي يعمل فعلًا؟

- **مشغل صوت حقيقي** — محرك Web Audio يولّد موسيقى لكل مقطع (مقام وسرعة وتتابع كوردات مختلف لكل أغنية)، مع تحليل طيفي حقيقي يحرّك مؤشر التشغيل. العرض/الإيقاف، السابق/التالي، التقديم/التأخير، الصوت والكتم تعمل كلها.
- **تشغيل ملفاتك** — زر الاستيراد (أو محرك «ملف من جهازك») يفتح MP3/WAV/M4A ويعرض المدة الحقيقية ويشغّلها كاملة.
- **بحث عربي ذكي** — يتجاهل التشكيل والتطويل وأخطاء الهمزات (أ/إ/آ)، ويدعم البحث بالكلمات الجزئية، مع نتائج مباشرة و«أفضل نتيجة».
- **مكتبة** — الأغاني المعجب بها، قوائم تشغيل حقيقية (إنشاء وحفظ)، فنانون.
- **مشغل كامل** — شاشة Now Playing مع كلمات متزامنة قابلة للنقر، وقائمة انتظار (إضافة/حذف/تشغيل).
- **تخصيص** — 6 سمات (Ink/OLED/Plum/Ocean/Dusk/Paper)، 7 ألوان تمييز + لون مخصص، كثافة، تقليل الحركة، تبديل اللغة.
- **عربي/إنجليزي** — RTL كامل وLTR كامل، خط عربي أولًا، وتبديل فوري لكل النصوص.
- **حفظ محلي** — السمة واللغة والإعجابات والقوائم ومستوى الصوت تُحفظ في المتصفح، مع زر استعادة الافتراضي.

## اختصارات لوحة المفاتيح

| `Space` | تشغيل / إيقاف |
| `N` / `P` | التالي / السابق |
| `←` / `→` | تقديم / تأخير 5 ثوانٍ |
| `M` | كتم الصوت |
| `S` / `R` | عشوائي / تكرار |
| `/` | التركيز على البحث |
| `F` | المشغل الكامل |
| `Esc` | إغلاق النوافذ |
| `?` | قائمة الاختصارات |

## الصوت

الموسيقى في النسخة التجريبية **مولّدة لحظيًا داخل المتصفح** (Web Audio API)، لذلك لا يوجد أي تحميل أو اتصال بخادم. ملفاتك المحلية تُشغَّل كما هي عبر `HTMLAudioElement` مع توصيلها بمحرك الصوت نفسه. الخطوط تُحمَّل من Google Fonts، ولو انقطع الاتصال تعمل بدائل النظام تلقائيًا.

## المصدر والبناء

```
src/index.html   الهيكل + الأيقونات
src/app.css      نظام التصميم كاملًا
src/app.js       البيانات، الترجمة، الحالة، محرك الصوت
src/ui.js        العرض والتفاعل والاختصارات
build.mjs        يدمج الكل في nagham-studio.html
```

```powershell
node build.mjs          # إعادة بناء الملف الواحد
node test\cdp.mjs       # 35 فحصًا وظيفيًا/بصريًا
node test\edge.mjs      # 28 فحصًا: الثبات، الاستعادة، الصوت المحلي، 320/900/1024/1920
```

الاختبارات تعمل على Chrome headless عبر DevTools Protocol، وتلتقط لقطات في `shots/`. آخر تشغيل: **63/63 ناجح، صفر أخطاء في الـ console**.

## ملاحظات

- الصفحة تعمل من `file://` مباشرة (تم اختبارها كذلك).
- لا تُرسل أي بيانات إلى أي خادم؛ كل الحالة محفوظة في `localStorage` على جهازك.
- لتغيير البيانات أو الأغنية الافتراضية: `src/app.js` ثم أعد البناء.
